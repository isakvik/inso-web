DOWNLOAD

inso is an osu! clone with Lua and GLSL shader support.
It integrates with existing osu! beatmaps.

DOWNLOAD Windows x64 / v{{VERSION}}

SETUP

Unzip the archive and add your songs to the songs/ folder. Run inso.exe after extracting.

DOWNLOAD Linux x64 / v{{VERSION}}

SETUP

Install libasound2 and ensure libGL and supported graphics drivers are available.

Unzip the archive and add your songs to the songs/ folder. Run inso after extracting.

older versions can be found on the releases page.

ISSUES

If you run into problems, ensure you have your latest graphics drivers; they may improve OpenGL support and/or performance.

If the issue persists, please report it on the GitHub issues page, or in the Discord.
