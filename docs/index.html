DOCUMENTATION

guides and reference material for making, running, and hosting inso maps.

GETTING STARTED set up inso and open your first map. COMMAND LINE available inso.exe flags and their effects. LAN TOURNAMENT MODE run synchronized play across multiple clients. LUA API the api reference generated directly from the game. INSO METADATA configure map behavior with an .inso file.

GETTING STARTED

unzip the latest release, add your songs to the songs/ folder, and run inso. maps can be opened with the open external button.

COMMAND LINE

the command-line reference will be expanded here. for now, the main flags are documented in the game readme.

LAN TOURNAMENT MODE

the tournament client waits for a start packet from inso_lan_broadcast, allowing several clients to begin a map together.

INSO METADATA

metadata reference will be added here. map authors can use an .inso file to configure scripts, shaders, and other map behavior.
